Description / abstract
Web-based CSV viewer that loads CSV files via URL or query parameter and displays them as an interactive table with paging, search, and sorting. Ships with quick-load samples including the Omeka S BulkImport Dublin Core layout. Built with Tailwind CSS, PapaParse, and DataTables.
