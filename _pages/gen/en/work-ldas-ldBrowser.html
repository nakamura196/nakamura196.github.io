Description / abstract
Enter a URI and the browser itself fetches the Linked Data and shows it as tables and graphs you can follow link by link. Reads Turtle, N-Triples, TriG, JSON-LD and RDF/XML, plus JSON-LD, microdata and RDFa embedded in HTML. Inspired by Masahide Kanzaki's LD Browser, rebuilt to run without a server.
