Description / abstract
In this study, first, we developed the “Hieratic Palaeography Database” that allows the user to search for the Hieratic script from elements such as Hieratic numbers, hieroglyphic numbers, and phonetic values. Second, we developed a search platform that contains the IIIF images of inscription, the linguistic data of Topographical List of Syrian and Palestinian regions, reference information, and geographical data for each city. This is an attempt to integrate open-data, open-annotations, open-evidence, and open-reference information.
