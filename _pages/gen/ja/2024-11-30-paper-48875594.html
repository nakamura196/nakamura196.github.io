概要
本研究では，デジタル保存の国際標準であるOAIS参照モデル（Reference model for an Open Archival Information System）に準拠したオープンソースソフトウェアArchivematicaを用いて，デジタル資料の保存用メタデータを検討する．我々は，東京大学史料編纂所が保有するデータを用いて，Archivematicaが作成した保存用メタデータ（Archival Information Package: AIP）を分析した．その結果，OAIS参照モデルに沿った構成のパッケージが作成されることと，真正性を維持するために必要な一部のメタデータが作成可能である点において，有効性が認められた．しかしながら，その過程では保存記述情報の選定および実装の難しさが課題として浮き彫りになった． This study examines metadata for preservation of digital materials using the open source software Archivematica, which conforms to the reference model for an Open Archival Information System (OAIS)，an international standard for digital preservation．We analyzed Archival Information Packages (AIPs) created by Archivematica using data held by the Historiographical Institute The University of Tokyo. The analysis demonstrated that the software effectively produces packages structured according to the OAIS reference model and can generate some of the metadata necessary to maintain authenticity. However, challenges related to the selection and implementation of preservation description information were highlighted.
