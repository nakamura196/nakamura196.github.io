This study examines metadata for preservation of digital materials using the open source software Archivematica, which conforms to the reference model for an Open Archival Information System (OAIS)，an international standard for digital preservation．We analyzed Archival Information Packages (AIPs) created by Archivematica using data held by the Historiographical Institute The University of Tokyo. The analysis demonstrated that the software effectively produces packages structured according to the OAIS reference model and can generate some of the metadata necessary to maintain authenticity.
